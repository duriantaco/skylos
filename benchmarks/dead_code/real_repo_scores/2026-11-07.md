## Verified disagreements and reproductions

- **Type-test entry:** p-queue's package script invokes `nz`, whose declared
  type-test input includes `test-d/index.test-d.ts`. The file is not orphaned.
  A neutral runner-root example retains a genuinely orphaned-file control.
- **Rust imports:** generic trait bounds, tuple-struct fields, associated
  constants and receiver traits provide actual consumers of the reported
  imports. Source and compiler evidence confirm the 18 active-source FPs.
  Minimal examples keep genuinely unused imports reportable.
- **Assign-only Swift field:** native typed AST shows that the apparent reads
  of `clearsOnMemoryPressure` resolve to the initializer parameter, while the
  private stored property is only assigned. A neutral reproduction preserves
  both a real field read and an unused-method control.
- **Periphery operator FP:** SwiftSoup's fileprivate `~=` declaration at
  `Sources/HtmlTreeBuilder.swift:776` is used implicitly by switch patterns at
  lines 81 and 83. Native AST binds those uses to that declaration. Removing
  only the operator in a private copy makes both matches fail to typecheck.
- **Swift incomplete analysis:** `CssSelector.swift` reproduces recursion;
  `Whitelist.swift` exhausts the name-resolution work budget. Both files are
  native-valid. Small original examples reproduce constructor-parameter
  rebinding recursion and a 20-call fluent-chain work failure. A distinct
  initializer binding and shorter chains complete. Bounds were not raised.

The neutral examples verify causes and controls; they are not included in the
natural-repository scores. There are no repository-name exceptions or detector
fixes in this measurement commit.
