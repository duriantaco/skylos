context_capabilities.json is generated from GitHub's webhook payload
schemas as published by Octokit (https://github.com/octokit/webhooks,
payload-schemas/api.github.com, commit
aa80c24a3f55354465b8b1438d33dd5602956d0d). Each payload field is classified
by its declared type: booleans, numbers, enums, date-times and documented
commit SHAs are fixed; strings with a format (uri, email, ...) or a pattern
are structured; other strings are arbitrary. The run-context keys
(github.sha, runner.os, ...) follow GitHub's contexts reference.

code_inputs.json lists action inputs whose value the action runs as code,
each confirmed against the action's own action.yml and source.
